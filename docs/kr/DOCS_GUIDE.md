# 문서 작성·관리 규칙

[English](../en/DOCS_GUIDE.md) | **한국어**

이 패키지의 문서는 영어와 한국어를 **각각 별도 파일**로 두고, 두 파일을 한 쌍으로 관리한다.

## 1. 위치와 짝

| 위치 | 내용 |
|---|---|
| `README.md` (패키지 최상위) | 첫 화면. 언어 선택 링크와 한 줄 소개만 둔다(본문 없음) |
| `docs/en/<이름>.md` | 영어 문서 |
| `docs/kr/<이름>.md` | 한국어 문서 — `docs/en` 과 **같은 파일 이름**이 짝 |

- 한쪽에만 있는 문서는 두지 않는다. 새 문서는 두 언어를 함께 만든다.
- 파일 이름은 영어로 쓴다(두 언어 공통).
- 두 언어 모두 패키지에 포함한다(다른 Mac 으로 복사할 때 함께 간다).

## 2. 각 문서의 머리

제목 바로 아래에 언어 전환 줄을 둔다. 지금 언어는 굵게, 다른 언어는 짝 파일 링크로 쓴다.

```markdown
# 제목

[English](../en/<이름>.md) | **한국어**
```

영어 문서는 `**English** | [한국어](../kr/<이름>.md)` 로 쓴다.

## 3. 두 언어를 맞추는 규칙

두 문서는 **한 줄씩 대응하는 번역**으로 유지한다. `tests/test_docs.zsh` 가 아래 구조를 비교한다.

| 비교 항목 | 같아야 하는 것 |
|---|---|
| 제목 | 단계(`#`, `##`, `###` …)와 순서, 제목 앞 번호(`2-1.` 등) |
| 표 | 절마다 표의 행 수 |
| 목록 | 절마다 목록 항목(`-`, `1.`) 수와 들여쓰기 |
| 코드 블록 | 블록 수, 언어 표시. 셸 블록(`sh`·`zsh`·`bash`·표시 없음)은 **주석을 뺀 명령 줄이 글자 그대로 같음** |

- 비교하지 않는 것: 일반 문단, 인용(`>`) 문단, 표·목록 안의 글. 한쪽 언어에만 필요한 설명은 일반 문단이나 인용 문단으로 쓴다.
- 셸 코드 블록 안에서는 `#` 주석만 번역한다. 명령·옵션·경로·규칙 문자열은 바꾸지 않는다.
- 측정값·버전·건수(예: 테스트 건수, 속도), "미검증" 표시는 두 언어에서 같게 둔다. 한쪽에서 바꾸면 다른 쪽도 같이 바꾼다.
- **화면 문구:** 실행 파일은 영어·한국어 화면을 모두 갖는다(언어 선택은 사용 설명서 2-5). 각 문서는 **자기 언어의 화면 문구를 그대로** 적는다. 예: 한국어 문서 `현재 폴더: 정리(clean)…`, 영어 문서 `Current folder: Clean…`. 화면 문구를 바꾸면(실행 파일의 `t '한국어' 'English'`) 두 문서의 해당 문구도 같이 고친다.

## 4. 고치는 순서

1. 한쪽 언어 문서를 고친다.
2. 짝 문서의 같은 위치를 고친다(같은 커밋·같은 작업에서).
3. 검사:
   ```sh
   zsh tests/test_docs.zsh
   ```
   전체 테스트(`zsh install.sh test`)에도 포함되어 있다.
4. FAIL 이면 출력된 차이(`-` = 영어, `+` = 한국어)를 보고 빠진 쪽을 채운다.

## 5. 새 문서 추가

1. `docs/en/<이름>.md` 와 `docs/kr/<이름>.md` 를 함께 만든다.
2. 2 의 언어 전환 줄을 넣는다.
3. 최상위 `README.md` 의 문서 목록에 두 언어 링크를 추가한다.
4. `zsh tests/test_docs.zsh` 로 확인한다.

## 6. 실행 파일의 화면 문구 (영어/한국어)

실행 파일은 파일 하나에 두 언어 문구를 함께 두고, 실행할 때 언어를 고른다(선택 순서는 사용 설명서 2-5).

| 파일 | 문구 쓰는 법 |
|---|---|
| `bin/*`, `install.sh`, `uninstall.sh`, `lib/common.zsh`, `zsh/ib-selftest.zsh` | `t '한국어' 'English'` — 맨 위의 공통 언어 선택 코드(`# ── 언어 선택` 블록)는 모든 파일에서 글자 그대로 같게 둔다 |
| `zsh/iterm-buttons.zsh` (셸에 읽혀 들어감) | `_ib_t '한국어' 'English'` — 셸 시작을 느리게 하지 않도록 첫 메시지 때만 언어를 정한다 |
| `python/open_in_tools.py` | `TITLES` 표의 `"kr"`·`"en"` 줄에 메뉴 이름을 함께 쓴다 |

- 새 문구는 처음부터 두 언어로 쓴다. 한국어만 쓰면 `tests/test_lang.zsh` 의 정적 검사가 FAIL 이 된다(한국어 주석은 괜찮다).
- 언어와 무관하게 그대로 둘 것: 확인 입력 `yes`, 메뉴 번호 `1/2/3/q`, 범주 이름 `cache/build/deps`, 옵션, 종료 코드, `--print0` 출력, 파일 표식(`# iterm2-tools:`), 우클릭 메뉴의 RPC 이름·고유 ID.
- 공통 언어 선택 코드를 바꾸면 모든 파일에서 같이 바꾸고, Python 의 `it2_lang` 과 버튼의 `_ib_t` 도 같은 규칙으로 맞춘다(테스트의 선택 순서 표로 확인).
- 테스트에서 화면 문구를 비교할 때는 언어를 고정한다(`export IT2_LANG=kr`). 영어 검사는 `IT2_LANG=en` 으로 따로 하고, 영어 출력에 한글이 없는지 본다.
- 화면 문구를 바꾸면 3 의 화면 문구 규칙대로 두 언어 문서의 해당 문구도 고친다.
- 확인:
  ```sh
  zsh tests/test_lang.zsh
  ```
  전체 테스트(`zsh install.sh test`)에도 포함되어 있다.
